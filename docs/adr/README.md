## Reading order

Start with **0011**: it states the three layers, the deterministic core's authority, and the
boundary rule that every AI path reads only `Scoped`. Read **0004** next — silent absence is the
disclosure discipline everything else respects. Then 0011's neighbours: **0001**, the `Picture`
contract at the seam, and **0003**, the honest empty-evidence state (`arvioimaton`) that 0004 and
0005 then tighten. Read **0019** for the conversational surface and the transparency duty it turns on, then **0018** for the classifier substitution and the accepted verifier risk it records, which supersedes **0009**'s vendor choice while keeping its contract. Finish with the most recent group, **0012–0015**, the Lifecare-corpus alignment
decisions on capacity, case restriction, record lifecycle and the source-aligned envelope. **0016** is
orthogonal to all of them: it decides the UI's design authority and presentation layer and changes no wire
field, policy input or selection behaviour, so it is safe to read last. **0017** is orthogonal in the same
way — it adds a response marking and changes no `Picture` field, policy input or selection behaviour. Read **0021** and then **0022**: together they record that the decision layer stays a typed call, that the protocol rather than an agent wrapper is what a reviewer inspects, and which Foundry capabilities were considered and refused.

**Before repeating any date, article, licence or vendor claim from an ADR, read
[`../references.md`](../references.md).** It is the primary-source citation layer for this decision log: one
table per question area, quoting what each source actually says, with a marked **Unverified** section and a
list of repository claims the sources do **not** support. Three ADR claims depended on sources that turned out
not to support them (the 200-token short-text threshold in 0017, the cited-only grounding restriction attributed
to the platform in 0009/0018, and "openEHR alignment" as partial conformance) and are corrected there and in
the records themselves.
